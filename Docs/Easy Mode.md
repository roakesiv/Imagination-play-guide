# Easy mode for families

Choose **Easy mode – make for me** at the top of the home page, pick a type, then tap **Generate random**. The idea comes with a prompt ready to copy into an image creator. Tap **Generate random** again for another idea, or open **Change the details** to keep the parts you like. [Open Easy Mode](https://roakesiv.github.io/Imagination-play-guide/#easy)

| Choose | What the prompt makes |
| --- | --- |
| Wall poster | A full-page US Letter picture |
| Party pictures | A US Letter sheet with four matching pictures to cut apart |
| Magic creature card | An illustrated profile card |
| Coloring page | A printable outline drawing |
| Surprise activity page | One of the maker’s individual worksheet or journal formats. The activity can also be selected under **Change the details**. |
| 10-page activity pack | A series of ten worksheets. Type **NEXT** in the image creator after each page. |

The options combine original characters, settings, palettes and other details using the same prompt generators as the guided makers. The first prompt uses the app’s preschool age setting, one version, and a description-only subject. Parents can change the age, photo choice, printing preferences and other applicable details. For a photo poster, attach the picture in the image creator.

Easy Mode holds its choices in the current page. Refreshing starts a new session. Saved creature cards and in-progress guided work stay in their existing places.

## Release checks

At 390 px and 1280 px, the first home action and direct link opened Easy Mode. Each of the six types produced a prompt without typing. The checks covered rerolls, edited preferences, the system clipboard, ten worksheet choices, guided poster subjects, and saved cards through reload and export. The ten creative question banks each contain 12 options, alongside the maker’s ten existing picture styles.
